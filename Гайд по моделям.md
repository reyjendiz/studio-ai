# Как добавлять модели в Студию

Короткая версия: кнопка **＋** рядом со списком моделей → выбери файл или вставь ссылку → укажи **тип** → «Добавить».
Главное — правильно выбрать тип. От него зависит, как модель запускается.

## 1. Добавление (2 способа)

**Файл с компьютера.** ＋ → вкладка «Файл с компьютера» → выбери `.safetensors` → проверь имя → выбери тип → «Добавить».
Большие файлы (10+ ГБ) грузятся минуты, полоса прогресса показывает ход.

**По ссылке.** ＋ → вкладка «По ссылке» → вставь прямую ссылку `https://…` на файл → имя подставится само → выбери тип → «Добавить».
- Hugging Face: открой файл на сайте, нажми «download» (правой кнопкой → копировать ссылку). Ссылка должна содержать `/resolve/`.
- Civitai: на странице модели правой кнопкой по кнопке Download → копировать ссылку (`https://civitai.com/api/download/models/…`). Если сайт требует вход, скачай файл в браузере сам и используй способ «Файл с компьютера».

Готовые модели сразу появляются в списке, самая новая выбирается по умолчанию.

## 2. Как понять тип модели

Открой страницу модели и найди **Base model** (на Civitai справа, на Hugging Face в тегах/карточке).

| Что написано на странице | Тип в окне «＋» | Где появится |
|---|---|---|
| Z-Image, ZImageTurbo (и дообучения на его основе) | Z-Image | Создать |
| SDXL 1.0, Pony, Illustrious, SD 1.5 (один файл-«чекпойнт») | SDXL / SD 1.5 | Создать |
| Qwen-Image 2.1 (в т. ч. NoctQ) | Qwen-Image 2.1 | Создать **и** Редактировать |
| FLUX.2 klein **4B** (обычная, не «base») | FLUX.2 klein 4B | Создать **и** Редактировать |

**Создать** (картинка по тексту): подходят все четыре типа.
**Редактировать** (твоё фото + инструкция): FLUX.2 klein 4B и Qwen-Image 2.1 (NoctQ).
Z-Image и SDXL не умеют править фото по инструкции, но в режиме «Создать» им можно подсунуть фото, и они его перерисуют (ползунок силы).

## 3. Какие дополнительные файлы нужны

Уже установлены и подхватываются сами:

| Тип | Энкодер | VAE | Шаги / cfg |
|---|---|---|---|
| Z-Image | `qwen_3_4b_fp8_mixed` | `ae` | 8 / 1 |
| FLUX.2 klein 4B | `qwen_3_4b_fp4_flux2` | `flux2-vae` | 4 / 1 |
| Qwen-Image 2.1 | `qwen3vl_8b_int8_convrot` | `qwen_image_2.1_vae_bf16` | 25 / 3 |
| SDXL / SD 1.5 | внутри файла | внутри файла | 28 / 6 |

Эти энкодеры и VAE **не удаляй**: они общие для всех моделей своего типа.

## 4. Что НЕ поддерживается (пока)

- Только `.safetensors`. Форматы `.ckpt`, `.pt`, `.bin` могут запускать код при загрузке, приложение их отклоняет. GGUF тоже нет.
- Другие архитектуры: FLUX.1, SD3, klein 9B, Qwen-Image-Edit, видео-модели и т. д. Им нужны свои энкодеры и свой workflow. Попросишь, и я добавлю новый тип.
- klein вариант **base** (`flux-2-klein-base-4b`) нужен с 20+ шагами и cfg выше 1, с текущими настройками выйдет плохо. Бери обычный `flux-2-klein-4b`.
- LoRA (маленькие дополнения к модели) пока не поддерживаются.

## 5. Как добавить новый тип или модель для редактирования

Скажи мне имя/ссылку модели. Мне нужно знать: файлы энкодера и VAE, рекомендованные шаги и cfg, пример промпта. Я добавлю workflow и пункт в список типов.
Для редактирования модель должна уметь принимать фото-образец (в описании пишут «image edit» / «reference images»).

## 6. Удаление

＋ → «Установленные модели» → «Удалить» → подтверди. Файл стирается с диска безвозвратно.

## 7. Если что-то пошло не так

| Симптом | Причина |
|---|---|
| «ComfyUI отклонил запрос» | неверный тип модели или нет нужного энкодера/VAE |
| «файл не похож на .safetensors» | ссылка ведёт на HTML-страницу, файл битый или это другой формат |
| «файл с таким именем уже есть» | поменяй имя или сначала удали старый файл |
| Картинки мусорные или серые | тип выбран неверно: удали модель и добавь заново с правильным типом |
| Первая генерация очень долгая | модель грузится с диска (минуты), потом секунды |
| «ComfyUI ещё запускается» | подожди около минуты |

## 8. Безопасность и лицензии

- Скачивай модели только с понятных источников, сверяй SHA256 (на Civitai и Hugging Face указан).
- Смотри лицензию на странице модели: многие дообучения (например на основе Qwen) только для некоммерческого использования.
- Не используй модели для создания изображений реальных людей без их согласия и ничего с несовершеннолетними.
